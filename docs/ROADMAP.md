# BetterNotes — Roadmap

## Done (MVP core)

1. Scaffold, theme, routing
2. Ink engine (pen/marker/eraser/lasso, pan/zoom)
3. Local persistence
4. Library UI
5. Basic templates + PDF import/export
6. Web/PWA + store basics

## Phase A — Editor workflow

1. TextBlock / OutlineNode / PaperTemplate models
2. Smart-Text v1
3. Deep outline sidebar
4. Custom paper creator
5. Infinite canvas toggle

## Phase B — Find, connect, GoodNotes UX

1. Global search
2. Tags + cross-links
3. GoodNotes-like dark chrome + horizontal toolbar
4. Document tabs, read/edit mode, thumbnail overlay
5. Shapes + images on page
6. Study mode
7. Local snapshots

## Phase C — Sync

1. Sync queue + dirty tracking (queue, deletes, prune)
2. CRDT-oriented block merge (id-keyed lists on pull)
3. Cloud adapter + status UI
4. Nearby / LAN sync (mDNS discovery + full snapshot with assets, then deltas)
